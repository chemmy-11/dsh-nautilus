## E31 令牌层落地（U1/U2）

### 1. 触发与背景（问题证据，可复现）

**症状**：宿主切暗色时工作台毫无变化——插件恒为浅色。

**判据**（不是「深色没做」，是**令牌源根本不存在**）：

```powershell
Select-String -Path src/client/*.ts -Pattern '--nt-[a-z0-9-]+' -AllMatches   # 改前：153 处引用
Select-String -Path src/client/*.ts -Pattern "--nt-bg\s*:"                 # 改前：0 处定义
Select-String -Path docs/2-dev/ui-s4-prototype.html -Pattern "--nt-bg\s*:" # 改前：仅原型（2 处）
```

预期：令牌层有唯一定义处。
实际（改前）：**153 处引用、0 处定义** → 每处 `var(--nt-*, <浅色值>)` 全部吃兜底，暗色主题无从生效。
根因：`workbench.ts` 头部注释称「`--nt-*` 令牌由 index.ts 注入」，而 `index.ts` 从未注入（**未兑现的注释**，与 dev-02 §7「令牌层落地步骤」同批规划、从未落地）。

**顺带查出**：`turn-annotate.ts` 引用的 4 个 `--dsw-alias-*` 名字在宿主别名表里**不存在** → 流内契合浮层一直吃硬编码浅色（暗色下白盒）。

```
--dsw-alias-fill-hover        = MISSING    （原用于 hover 底）
--dsw-alias-border-secondary  = MISSING    （原用于浮层边 / 选项边 / 输入框边）
--dsw-alias-border-accent     = MISSING    （原用于选中档）
--dsw-alias-surface-primary   = MISSING    （原用于浮层面）
--dsw-alias-interactive-bg-hover = EXISTS  （修正后的 hover 底）
--dsw-alias-border-l2 / -l4      = EXISTS  （修正后的两条线）
```

### 2. 宿主主题机制实测（dsh 0.1.7-rc.1 安装树，只读）

| 事实 | 出处（已核） |
|---|---|
| 暗色选择器 = `body[data-ds-dark-theme]` | `@deepseek-ai/dsh-client-ui-layout/lib/types/client/theme-presenter.d.ts` → `export declare const DARK_ATTRIBUTE = "data-ds-dark-theme"` |
| 呈现器投影四项：`html{color-scheme}` · 该 body 属性 · body 内联 `--dsw-alias-*` · `--dsh-content-font-size` | 同文件 `ThemePresenter.apply` 文档块 |
| 亮/暗两套别名表由主题包样式表给出 | `@deepseek-ai/dsh-client-ui-theme/lib/client.js` 内联 CSS（17071 字符：`body` 与 `body[data-ds-dark-theme]` 两块各 77 静态 + 91 别名） |
| 用户偏好三态 `light`/`dark`/`system` | `dsh-client-ui-theme/lib/types/theme-settings.d.ts`（`THEME_PREFERENCES`） |
| 宿主服务 `ctx.theme`（`getTheme` / `theme/change` / `setTheme` / `overrideTokens`）存在 | `dsh-client-ui-theme/lib/types/client/index.d.ts` |

**结论**：跟随只需以 `body[data-ds-dark-theme]` 为令牌块选择器——**纯 CSS，无需 JS 监听**（宿主换肤 → 属性翻转 → 令牌整块切换，与宿主零竞态、零闪烁）。`ctx.theme.setTheme` 会连用户偏好一起改写 → **不用**（「观测，不干预」红线）。

**面层映射实测**（决定 §2.3 的绑定纪律）：

```
DSH 浅色：bg-base = bg-layer-1 = bg-layer-2 = bg-layer-3 = var(--dsw-static-neutral-bluish-00) = #fff   ← 四级同值
DSH 暗色：bg-base=#151517 · layer-1=#232324 · layer-2=#2c2c2e · layer-3=#353638                    ← 四级分明
```

→ 面层若绑宿主，浅色下工作台整片白、S4「图纸底 / 白卡片 / 次级面」层次被抹平；故面层自持定版值（§2.3 ②）。
→ 墨线绑宿主的复合值几乎重合定版：`border-l2` 10% 黑压 `#f2f2f0` = `#d9d9d8` ↔ S4 `#d9d9d5`；`border-l4` 16% 黑 = `#cbcbc9` ↔ S4 `#c8c8c3`；暗色 `border-l2` 12% 白压 `#1a1b1d` = `#363738` ↔ S4 `#35363a`、`border-l4` 20% 白 = `#48494a` ↔ S4 `#4a4b50`。
