## 4. 诚实边界（引用本条必须一并引用）

1. **端上未验**：本轮只证到「源码契约（SSR + 源码级守卫）+ 产物哨兵」；§3 六步需守谷人刷新既有页面目视，**未确认前不得宣称 A.4 UI 续作交付完成**。
2. **未裁决口径未改**：`reportStatus==='pending'` 不计入未裁决（语义＝先读报告再裁决）是本轮**只记录不擅改**的既有口径；其代价（报告长期卡 pending 时该行不进徽标）已写进 dev-02 §3.2，改动须先出方案裁决。
3. **手动档盲区条只表达「没在看」**：它不是说「一定越线了」；自动档下的静默同样可能来自采集器故障（`collector.lastError`），本视图未呈现采集器健康度——属总览 FIG.01 的职责，不在此重复。
4. **报告仍是原文直排**：只换排版不引 markdown 渲染器（零依赖纪律），故表格/加粗等语法在面板里是**字面文本**；要富文本渲染需另立提案。
5. **规格入册 ≠ 交互定版**：§3.2 是「按实现回写并补纪律」的定版，其中**盲区条、口径注记、报告排版三件为本轮新增设计**，视觉观感仍待守谷人裁决（若判「太吵」，注记可折叠为 `<details>`）。
